# Retro Arcade

Free neon arcade collection for iOS and Android. Built with Vite, TypeScript, and Capacitor.

## Games

- Neon Serpent (Snake)
- Block Drop (Tetris)
- Alien Siege (Space Invaders)
- Brick Blaster (Breakout)
- Neon Pong
- Rock Dodger (Asteroids)
- Maze Chomper
- Barrel Run
- River Hopper
- Star Squadron

## Play online

[ronparada.github.io/retro-games](https://ronparada.github.io/retro-games/)

## Run locally

```bash
npm install
npm run dev
```

## Build for mobile

```bash
npm run cap:sync
npm run cap:android   # requires Android Studio
npm run cap:ios       # requires Xcode on macOS
```
